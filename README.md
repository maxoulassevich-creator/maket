# Foodbeer / «ФудБир» — проектирование интерфейса

Репозиторий проектной документации по интерфейсу гастромаркета Foodbeer: сайт на WordPress + WooCommerce (публичная информационная витрина без корзины для физлиц, закрытый оптовый контур со счётом на предоплату, модуль публикаций на сайт и в Telegram, интеграция с 1С:УНФ).

## Состояние

Этапы 0–5 выполнены. **Производство (этап 6) не начато — ждёт согласования формата.**

## Изображения товаров

`assets/products/` — 45 подготовленных изображений (1254×1254, PNG с прозрачным фоном), разложенных по девяти категориям каталога из ТЗ 12.1, по пять на категорию. Карта соответствия исходным файлам — `assets/products/index.json`.

Используются в плитках категорий и карточках товара. Стоки не подставляются.

## Жёсткие правила интерфейса

Действуют во всех макетах без исключений:

1. У публичного посетителя нигде нет корзины, мини-корзины, кнопки «Купить», бронирования и предзаказа. Этих элементов **нет в разметке**, а не спрятаны стилями.
2. Шапка обслуживает три роли: гость видит «Войти» и «Опт»; заявитель — статус заявки; подтверждённый оптовик — название организации, скидку и корзину с суммой.
3. Цена всегда с единицей измерения: «за 100 г», «за шт», «за бутылку».
4. Блок «Коротко» — абзац 40–70 слов сразу под заголовком, почти на каждой странице.
5. Незаполненные данные не показываются вообще — ни прочерком, ни заглушкой. Секция без данных скрывается целиком.
6. Цвет статуса никогда не единственный носитель смысла — рядом всегда подпись.
7. Числа в таблицах моноширинные, по правому краю.
8. Онлайн-оплаты нет. Везде, где заканчивается оформление, стоит явное пояснение про счёт на предоплату.
9. Придуманные данные запрещены (ТЗ 7.5): цена, остаток, состав, страна, производитель, срок годности, срок акции и размер скидки не создаются без источника.
