# Референсы

`organi-frames/` — все 20 фреймов исходного макета Figma «Organi Organic»
(`baj6j5MCoJBq8tDRUGzEXo`), выгруженные через Figma REST API в PNG (scale 0.5).

Имена файлов совпадают с именами фреймов в Figma. Соответствие node-id —
в `docs/01-инвентаризация-макета.md`, п. 1.2.

Изображения товаров внутри фреймов не отрисовались: в исходнике это ссылочные
image-fill, которые API отдаёт пустыми. На структуру, сетку, типографику и
цвета это не влияет — именно они и снимались с этих рендеров.
