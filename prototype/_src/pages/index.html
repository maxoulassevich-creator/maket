Прототип Foodbeer

Указатель страниц

Прототип собран на дизайн-системе, извлечённой из макета «Organi Organic». Внизу экрана — служебная панель: переключатель роли (гость / заявитель / подтверждённый оптовик) и кнопка «Аннотации», которая показывает разбор каждой секции по схеме Что / Как / Зачем со ссылкой на источник требования.

✓ Роль переключает разметку, а не стили Содержимое для чужой роли лежит в <template> и в DOM не попадает. Откройте инспектор под гостем — узла корзины и кнопок покупки там нет. Это прямое требование ТЗ 4.1: «скрытие кнопок только средствами CSS не допускается».
⏳ Состояние работы Собрано 6 страниц из 35. Остальные перечислены ниже как запланированные — порядок производства и приоритеты в docs/04-пробелы.md, соглашения по вёрстке в docs/06-производство.md.
