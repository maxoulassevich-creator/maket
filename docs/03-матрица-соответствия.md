Три вердикта: **ПОДХОДИТ** (меняется только контент), **АДАПТИРОВАТЬ** (перечислено, что убрать/добавить/переставить), **НЕ НУЖЕН**.

### 1. `Home Page 1` — АДАПТИРОВАТЬ (донор для `/`)

Самый богатый секциями вариант, из него берётся каркас главной.

**Убрать:** hero с поиском на кирпичной стене (Foodbeer начинает с заголовка и живого счётчика, а не с поиска); три цветных промо-баннера (жёлтый/оранжевый/зелёный — чужая интонация); инфографику «6 подписей вокруг картинки»; блок «Protein Powders» с видео; «Best Deals» с прогресс-баром «Sold: 62/100» (продажи поштучно не считаются, число будет выдуманным — прямой конфликт с ТЗ 7.5); баннер «100 % Secure Delivery» (доставки нет, ТЗ 10.4); отзыв-цитату и карточки команды (команда переезжает на `/about/`); блок «4 иконки-гарантии» (Free Shipping / 30 Day Return — ничего из этого нет); Instagram-ленту.

**Оставить и перекрасить содержимым:** плитки категорий (5 в ряд → **9 плиток**, с числом позиций и ценой «от»); сетку товаров с табами → «Привезли на этой неделе»; блок «Popular Organic Discount» с таймером → «Действующие акции» (таймер тут по делу — «Структура» прямо требует обратный отсчёт); блок «журнал» (крупная статья + список) → «Материалы журнала».

**Добавить (доноров нет):** служебную полосу со статусом «открыто/закрыто»; первый экран с живым счётчиком позиций и датой обновления; полосу трёх фактов; блок «Коротко»; «Подбор по задаче»; блок «Второй этаж» на фирменном зелёном; блок «Оптовым покупателям»; блок Telegram; блок вопросов и ответов; контакты с картой.

**Переставить:** порядок секций задаёт «Структура», он другой.

### 2. `Home Page 2` — НЕ НУЖЕН как страница, **донор секций**

Полноценной второй главной у Foodbeer нет. Но три приёма ценные:
- блок «две картинки лесенкой + текст с вертикальной зелёной чертой-цитатой» → донор для `/about/` и `/second-floor/`;
- «Best Trending» — три цветные карточки → донор для «Подбора по задаче» (сценарные подборки);
- «Sale 68 % Off» на бежевой скруглённой заливке во всю ширину → донор для контрастных блоков.

### 3. `Home Page 3` — НЕ НУЖЕН как страница, **донор двух элементов**

- Двухъярусная шапка с кнопкой «All Departments» → **лучший донор шапки Foodbeer**: в ней есть отдельная кнопка каталога, широкий поиск и правая зона. Именно её нужно разложить на три состояния роли.
- Карточка товара в раскрытом состоянии («Add to Cart» + «Quick View») → показывает механику ховера; для публичной плитки Foodbeer эти кнопки **не переносятся вовсе**, но для оптовой плитки механика подходит.

### 4. `Home Page 4` — НЕ НУЖЕН как страница, **донор двух элементов**

- Горизонтальная карусель товаров, выходящая за края контейнера → донор для «Привезли на этой неделе» и «Часто берут».
- Таймер карточками (28 days / 25 hours / 57 mins / 36 secs) → более читаемый вариант обратного отсчёта для акций, чем строчный.

### 7. `add_to_cart_page` — АДАПТИРОВАТЬ (донор для `/cart/`)

Единственный экран, на котором есть таблица позиций с количеством и итогом. Каркас годится.

**Оставить:** таблицу позиций, счётчик количества, кнопку удаления строки, поле промокода, итоговую панель.

**Изменить:** столбцы. В Organi ФОТО / НАЗВАНИЕ / ЦЕНА / КОЛИЧЕСТВО / ИТОГО. «Структура» требует: товар, **артикул**, **единица измерения**, количество, **розничная цена**, **персональная цена**, сумма — то есть две цены рядом, а не одна. Итоговая панель тоже сложнее: сумма по рознице, каждая скидка отдельной строкой, итог, **размер предоплаты**, отметка о минимальной сумме заказа.

**Добавить:** предупреждение об изменении цены (старое и новое значение с причиной, заказ не создаётся до подтверждения); пояснение о совместимости скидок; напоминание под кнопкой, что онлайн-оплаты нет и придёт счёт; пустое состояние корзины; пометку позиции, ставшей недоступной.

**Исправить дефект исходника:** в заголовочной плашке написано «Faqs Page».

### 13. `product_detail_v1` — АДАПТИРОВАТЬ (донор для `/product/…`)

Круглое изображение с декоративным листом — не для гастрономии, где важен срез. Но правая колонка (рейтинг, метка, заголовок, описание, таблица характеристик, счётчик, кнопка, теги, шеринг) и нижние табы годятся.

### 14. `product_detail_v2` — **ПОДХОДИТ лучше, чем v1** (основной донор карточки товара)

Классическая раскладка: лента миниатюр слева, крупное изображение, справа — данные. Для гастрономии это верно: «в гастрономии решение принимается глазами: видна ли текстура среза».

**Убрать:** рейтинг и «Read 3 Reviews» (отзывов на сайте нет ни в ТЗ, ни в «Структуре» — были бы выдуманные данные); «Nutritional Values» заменить на таблицу характеристик Foodbeer (тип, молоко, выдержка, регион, формат продажи, хранение, срок годности); «TAGS/SHARE» — по усмотрению.

**Изменить:** блок цены и действия — **три варианта вместо одного**: публичный (цена с единицей + «товар забирают в магазине», кнопок покупки нет), оптовый (персональная цена рядом с зачёркнутой розничной, количество, «В корзину»), алкогольный (цена как справка + плашка ограничения вплотную к цене).

**Добавить:** блок «Коротко»; заметку продавца с именем, должностью и датой; «С чем сочетать»; «Чем заменить»; вопросы и ответы; блок «Оптовым покупателям».

Каталог без сайдбара. Оставить строку управления (переключатель вида, счётчик результатов, сортировку), сетку 4×2, пагинацию. **Убрать** секцию отзывов внизу. Добавить заголовочный блок, «Коротко», метки подкатегорий, текст «Как выбрать», вопросы и ответы, «Смотрите также», «Оптовым покупателям».

### 16. `shop_list_side_bar` — **ПОДХОДИТ как каркас** (основной донор для `/catalog/сыры/`)

**Изменить:** список фильтров. В Organi — категория и цена. Нужны: категория, цена, **страна, производитель, формат, признаки, наличие**. Добавить метки выбранных условий с быстрым сбросом и счётчик найденного, пересчитываемый **до применения** — этого в Organi нет.

### 17. `shop_list_view_sidebar` — ПОДХОДИТ (вид списком)

Второй режим отображения. Берётся как есть, с той же заменой блока цены/действия на три ролевых варианта.

### 18. `compare_page` — НЕ НУЖЕН как страница, **донор таблицы**

Сравнения товаров ни в ТЗ, ни в «Структуре» нет. Но раскладка «левый столбец параметров с иконками + N столбцов-объектов» — прямой донор для четырёх обязательных таблиц: «Что нужно знать о каталоге» (3 столбца: что / как здесь / почему так), «Как отбирается ассортимент» (принцип → что это значит), «Что нужно для регистрации» (поле / обязательность / зачем), «Как считается цена» (пример расчёта).

### 19. `Newsletter_Popup` — НЕ НУЖЕН

Попапа подписки в проекте нет. Приём «круглая иконка, наполовину выступающая за верхнюю границу карточки» можно переиспользовать в состоянии заявки и в сообщении «Заказ оформлен».

### 20. `quick_view_popup` — АДАПТИРОВАТЬ, низкий приоритет

Быстрый просмотр в документах не описан. Для публичного посетителя он вообще спорен: единственное действие в нём — «Order Now», которого быть не должно. Может пригодиться оптовику для быстрого добавления в корзину. Вне обязательного объёма — см. вопрос №5.

## 3.4. Чего у Organi нет ни в каком виде

Ни одного донора не нашлось для:

1. **Состояний роли в шапке.** Во всех четырёх вариантах шапки правая зона одинакова: профиль, избранное, зелёная корзина со счётчиком «2». Это ровно тот элемент, которого публичный посетитель Foodbeer видеть не должен, и ровно то место, где должны появиться три состояния.
2. **Личного кабинета.** Восемь страниц `/account/…` не имеют прототипа: нет ни бокового меню кабинета со счётчиками, ни сводки условий, ни истории заказов, ни счетов.
3. **Оформления заказа и счёта.** Ни `/checkout/`, ни `/checkout/received/`, ни работы с PDF-документом и его версиями.
4. **Форм с проверкой.** Ни ошибки у поля, ни обязательной пометки, ни маски, ни блокировки повторной отправки.
5. **Статусов.** Ни одного цветового статуса с подписью — при 10 статусах заказа (ТЗ 17), 3 статусах заявки и статусах счёта.
6. **Плашек-ограничений.** Ни информационной, ни предупреждающей, ни запрещающей. Плашка алкогольного ограничения, «онлайн-оплаты нет», предупреждение об изменении цены — всё с нуля.
7. **Пустых состояний.** Ни пустой корзины, ни пустого поиска, ни пустой категории, ни отсутствия заказов, ни 404, ни служебного сообщения.
8. **Мобильных раскладок.** Ни одного фрейма уже 1920.
9. **Моноширинных чисел в таблицах.**
10. **Алкогольной витрины в любом виде.**
